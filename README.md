# 아이슬란드·핀란드 여행 웹앱 — 배포 방법

## 1. GitHub Pages에 올리기

1. GitHub에서 새 저장소(repository)를 만들어요. 이름은 아무거나 (예: `iceland-finland`)
   - **Public**으로 만들어야 무료로 Pages를 쓸 수 있어요
2. 이 폴더 안의 **모든 파일**을 저장소에 업로드해요
   - 웹에서 하려면: 저장소 → `Add file` → `Upload files` → 파일 전부 드래그 → `Commit changes`
   - `images` 폴더도 같이 올라가야 해요
3. 저장소 → `Settings` → 왼쪽 메뉴 `Pages`
4. **Source**를 `Deploy from a branch`, **Branch**를 `main` / `/ (root)`로 두고 `Save`
5. 1~2분 뒤 주소가 나와요:
   `https://<사용자이름>.github.io/iceland-finland/`

> ⚠️ 파일들이 저장소 **최상단**에 있어야 해요. `index.html`이 하위 폴더에 들어가면 주소가 달라져요.

## 2. 휴대폰에 설치하기

1. **크롬**으로 위 주소를 열어요 (삼성 인터넷도 됨)
2. 우측 상단 `⋮` → **홈 화면에 추가** → 추가
3. 홈 화면에 앱 아이콘이 생겨요. 이제 앱처럼 열려요

## 3. 오프라인으로 쓰려면 (중요)

**출발 전, 와이파이가 되는 곳에서 한 번만** 해두세요.

1. 앱을 열고 아래 **일정 전체** 탭으로 들어가요
2. **`이 지역 지도 미리 저장`** 버튼을 눌러요
3. 진행 막대가 100%가 될 때까지 기다려요 (레이캬비크·남부해안·헬싱키 3개 구역, 1~2분)
4. "저장 완료" 문구가 뜨면 끝

이렇게 하면 아이슬란드·핀란드에서 데이터가 없어도:
- 일정 / 맛집 목록 / 체크리스트 → 전부 그대로 보여요
- 지도 → 저장한 지역은 그대로 보여요 (남부해안 구간은 큰 지형만 보이는 낮은 해상도예요)
- 내 위치(GPS) → 데이터 없이도 작동해요

단, **길찾기 버튼**은 구글맵을 여는 거라 인터넷이 필요해요.
현지 내비게이션까지 필요하면 구글맵 앱에서 해당 지역을 `오프라인 지도`로 따로 받아두시는 걸 같이 권해요.

## 4. 체크리스트 사용법

- 항목을 탭하면 체크/해제되고, 휴대폰에 그대로 저장돼요 (앱을 껐다 켜도 유지)
- 상단 **전체 초기화**를 누르면 모든 체크가 지워져요 (되돌릴 수 없어요)

## 5. 맛집 필터 사용법

- 카테고리 칩을 누르면 **그 카테고리만** 보여요 (한 번에 하나만 선택되는 방식)
- 같은 칩을 다시 누르거나 **전체**를 누르면 전체 목록으로 돌아가요
- 지도 화면에서 🍽️ 버튼을 켜면 선택된 카테고리만 지도에 점으로 표시돼요

## 6. 내용을 고치고 싶을 때

- 일정·맛집·체크리스트 데이터는 `app.js` 맨 위 `var DATA = {...}` 안에 들어 있어요
- 고친 뒤 GitHub에 다시 업로드하면 반영돼요
- **단**, 휴대폰에 캐시가 남아 옛 내용이 보일 수 있어요.
  그럴 땐 `sw.js` 첫 줄의 `var VERSION = 'v1';` 을 `'v2'`로 바꿔서 같이 올리면
  자동으로 새 내용을 받아와요.

## 파일 설명

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조 |
| `styles.css` | 디자인 (폭 360dp 기준, 본문 17px) |
| `app.js` | 일정·맛집·체크리스트 데이터 + 동작 |
| `sw.js` | 오프라인 캐시 (서비스 워커) |
| `manifest.webmanifest` | 홈 화면 추가용 설정 |
| `leaflet.js` / `leaflet.css` | 지도 라이브러리 (외부 CDN 대신 내장) |
| `images/` | 지도 라이브러리 기본 이미지 |
| `icon-*.png` | 앱 아이콘 |
